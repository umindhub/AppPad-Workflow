# Terms for the AppPad Workflow Market

This repository is **not open source**. It holds the workflows published in the AppPad
Workflow Market and the tools that check and publish them.

## 1. Workflows (`workflows/<id>/`)

Each workflow belongs to its author(s), named in its `market.json`. Copyright stays with them.

By opening a pull request that adds or changes a workflow, you confirm that you wrote it or
have the right to submit it, and you grant YouMindHub a worldwide, non-exclusive, royalty-free
license to review, host, copy, display and distribute it through the Workflow Market,
youmindhub.com and AppPad, and to make the technical changes needed to publish it (for example
adding an icon URL). The license lasts until the workflow is removed from the market.

YouMindHub may decline, change the listing of, or remove any workflow at any time, for any
reason, including after it was published.

## 2. People who install a workflow

You may install, run and change a workflow on your own Macs. Sharing or selling a copy
outside the Workflow Market needs the author's permission.

## 3. Removing a workflow

An author can remove their workflow with a pull request that deletes its folder. Copies
already installed on users' Macs are not removed; AppPad tells their users the workflow is no
longer in the market.

## 4. Not allowed

Malware; code that is obfuscated, minified or downloaded and run at runtime; collecting or
sending data the user didn't ask for; ads or tracking; crypto mining; anything that breaks the
law or someone else's rights.

## 5. No warranty

Workflows are reviewed before they are published, but are provided "as is", without warranty
of any kind. You run them at your own risk. AppPad asks before a workflow uses any of the
permissions it declares.

## 6. Everything else

Everything outside `workflows/` (scripts, GitHub Actions, documentation, the workflow format
description) is © YouMindHub. All rights reserved.
